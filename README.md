# WiFi Calling (VoWiFi) 一键检测

## 这是什么

一个小脚本，帮你回答一个问题：**这台 VPS 的网络，能不能让欧洲、美国、菲律宾的手机卡用 WiFi 打电话？**

WiFi Calling 就是手机连上 WiFi 后照样能打电话、收短信，原理是手机通过网络连回运营商的服务器。脚本会替你把这条路走一遍，告诉你通不通。

## 怎么用（三步）

**第 1 步**：用 SSH 连上你的 VPS（就是你平时装东西的那个黑窗口）。

**第 2 步**：把下面这一行完整复制，粘贴进去，按回车：

```bash
curl -fsSL https://raw.githubusercontent.com/imthnio/wificalling-jiance/main/check.sh | bash
```

**第 3 步**：等半分钟，看最后的"检测结论"。不用你输任何东西，什么都不用装。

## 看懂检测过程

先显示检测进度（检测中... 8/39），测完后一行就是一家运营商，比如：

```
  ✅ 德国 Telekom
  ✅ 法国 Orange
  ❌ 英国 EE
```

- `✅` = 这家运营商的卡能用 WiFi 打电话，`❌` = 不能用，就这么简单
- 最后有"总结"：能用几家、具体是哪些、不能用几家，再加一句"检测结论"直接告诉你这台 VPS 行不行、为什么、怎么办

## 结果是"能"——还要注意 5 件事

检测通过只代表"路是通的"，手机那边还要满足下面 5 条，缺一条都用不了：

1. **你的手机号码开通了 WiFi 通话**：有些运营商默认没开，去运营商 App 里找找，或打客服电话开。
2. **你的手机支持**：不是所有手机都行，还要在设置里把"WiFi 通话"开关打开。
3. **手机流量要走这台 VPS 出去**：脚本测的是 VPS 的网络，你得让手机通过代理 / VPN 从这台 VPS 上网，否则测了白测。
4. **运营商可能变卦**：有些运营商会拉黑机房 IP，今天能用不代表下个月还能用。哪天突然不行了，重跑一遍这个脚本看结果。
5. **离得越近通话越清楚**：VPS 离运营商服务器越近延迟越低，跨国绕太远打电话会有延迟感。

## 常见疑问

- **要装东西吗？** 不用。纯 bash 编写，零依赖，连 64MB 内存的小鸡都能跑。
- **要输入什么吗？** 不用，全自动。
- **会不会很慢？** 39 家运营商一起测，半分钟左右出结果。
- **对运营商服务器有影响吗？** 没有，每家只发两个很小的测试包。
- **我是 NAT 网络（比如 NAT 小鸡、路由器后面），要映射哪几个端口？**
  先说结论：**WiFi 打电话只走"出站"，正常 NAT 什么都不用映射**，路由器、光猫都不用动，家里的网直接就能用。
  只有"别人要从外面连进来"时才需要映射端口，比如你在 VPS 上自己搭了 IPsec VPN 服务器。要映射就加这两个（都是 UDP，不是 TCP）：
  - UDP 500
  - UDP 4500
  注意：脚本报"UDP 被拦"是指"出站"被拦，端口映射管的是"进站"，加了也解决不了，得去服务商后台把 UDP 出站放开。
